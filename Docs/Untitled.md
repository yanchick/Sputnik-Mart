#### **Модуль 3: Оркестрация и трансформация (ETL/ELT)**

*   **Цель модуля:** Автоматизировать весь процесс от сбора до трансформации данных с помощью оркестратора Apache Airflow.

*   **Теоретическая часть (Лекция):**
    *   **1. Введение в оркестрацию:**

    *   **2. Анатомия Apache Airflow:**

        *   Connections & Hooks: безопасное хранение учетных данных.
        *   XCom(XComs): как передавать небольшие объемы данных между задачами.

        *   Атомарность задач: каждая задача выполняет одно логическое действие.
        *   Параметры DAG: `schedule_interval`, `start_date`, `catchup`, `tags`.
    *   **4. Трансформация данных с Polars/Pandas:**
        *   Что такое `Polars` и почему он может быть быстрее `pandas`? (Многопоточность, ленивые вычисления).
        *   Основные операции: чтение Parquet, объединение (join), агрегация (group by), очистка данных (удаление дубликатов, заполнение пропусков).

        *   Объединяет данные из API и скрейпинга по `product_id`.
