# Этапы реализации (Milestones M0–M4)

Дорожная карта из §12 ТЗ. Каждый этап закрывается критериями из [[acceptance]],
применимыми к его сервисам.

## Общий критерий готовности

Этап готов, когда сервисы этапа поднимаются нужным профилем и проходят свои
чек-боксы приёмки + сквозной сценарий из ТЗ §10.

## M0 — Каркас и генераторы

| Что | Содержание | Критерий |
| --- | --- | --- |
| M0 | Репозиторий, docker-compose каркас, генераторы базовых данных | Поднимается профиль `base` |

- Монорепозиторий + `specs/` (см. [[adr/ADR-0005 — Contract-first монорепо]]).
- Пакет `sim` (см. [[adr/ADR-0002 — Генераторы пакет sim]]) с детерминированными выдачами.
- Профиль `base` запускается одной командой.

## M1 — Фасад

| Что | Содержание | Критерий |
| --- | --- | --- |
| M1 | Фасад: каталог, кабинет, API, Swagger | Базовые практики 1–4 |

- `api-gateway`, `identity`, `catalog`, `order`, `delivery`, Postgres.
- Swagger/OpenAPI UI доступен; кабинет покупателя работает.

## M2 — Content-нить

| Что | Содержание | Критерий |
| --- | --- | --- |
| M2 | `sensor-gateway → Kafka → bronze → silver → gold` | Валидация и хранилища |

- Профиль `adv`; MinIO, Redpanda (см. [[adr/ADR-0004 — Event bus Redpanda]]).
- DLQ и Quality-page; сценарий `sim-dirty`.

## M3 — Commerce-нить + Airflow

| Что | Содержание | Критерий |
| --- | --- | --- |
| M3 | Commerce-нить + Airflow + доставка подписок | Сквозной прогон |

- Топики `commerce.*`; DAGи §8 ТЗ; доставка свежих чтений подписчику по SSE.

## M4 — Observability, CI/CD, GDPR

| Что | Содержание | Критерий |
| --- | --- | --- |
| M4 | Observability, CI/CD, GDPR | Сводный прогон |

- GitHub Actions: валидация контрактов + тесты блокируют деплой (§9 ТЗ).
- Псевдонимизация PII; ограничение доступа к слою gold.

## Порядок и зависимости

```
M0 ─► M1 ─► M2 ─► M3 ─► M4
      (фасад)   │      │
                ▼      ▼
            M2/M3 опираются на M0 (генераторы, шина)
```

Продвинутый уровень (профиль `adv`) начинает входить с M2; базовый (профиль
`base`) полностью закрывается на M1 + чтение итогов M2–M4 в демо-режиме.
