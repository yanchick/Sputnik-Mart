# Журнал архитектурных решений (ADR log)

Каждое значимое решение фиксируется в виде ADR: **контекст → решение →
последствия**. Решения переносятся из «Открытых вопросов» [[../../ТЗ — Демо-портал маркетплейса данных (SDD)]] по мере их принятия.

## Статусы

- `Предложен` — обсуждается, код под него не пишем.
- `Принят` — решение действует, реализуем.
- `Суперседирован` — заменён более поздним ADR (указать каким).
